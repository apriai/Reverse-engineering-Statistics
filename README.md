# Reverse engineering - Statistics

Calculadora Trader Estadistico de probabilidades, simulación y esperanza matemática para prop firms.

## Uso

Descarga los archivos juntos y abre index.html en tu navegador. No necesita servidor, instalación ni claves API. Las fuentes de Google requieren conexión; sin ella se usan las fuentes alternativas.

El enlace Presentacion abre presentacion.html en otra pestaña.

## Archivos

- index.html: calculadora, estilos y lógica.
- presentacion.html: presentación original adjunta; sus cifras son ilustrativas y no se sincronizan con la calculadora.
- trader-estadistico-logo.png: logo.

Las probabilidades son estimaciones del modelo, no tasas de acierto históricas ni promesas de ganancias.

Esta es una copia independiente: los cambios posteriores en Replit no se sincronizan automáticamente.
